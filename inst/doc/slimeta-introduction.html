Introduction

The slimeta package implements the Stacked Linear Mixed-Effects (SLIM) framework for multivariate meta-analysis with correlated endpoints, as described in:

Rabbee N. (2026). Translating treatment effects between correlated endpoints. BMC Medical Research Methodology. https://doi.org/10.1186/s12874-026-02852-x

Clinical researchers frequently need to answer: “If a treatment changes endpoint 1 by X%, what change in endpoint 2 should we expect?” The SLIM framework addresses this by defining the Expected Translational Association (\(\eta\)), which translates treatment effects across correlated endpoints without assuming a directional or parametric relationship between them.

SLIM enables:

  1. Joint modeling of multiple endpoints across studies
  2. Estimation of between-study correlation structure
  3. Translation of treatment effects between endpoints via eta
  4. Hypothesis testing for effect heterogeneity across strata
  5. Sample size calculations for trial design

Mathematical Framework

The SLIM Model

For study \(i\) and endpoint \(j\): \[Y_{ij} = \mu_j + u_{ij} + \varepsilon_{ij}\]

where:

  • \(\mu_j\) = population mean for endpoint \(j\)
  • \(u_{ij}\) = study-level random effect
  • \(\varepsilon_{ij} \sim N(0, V_{ij})\) = sampling error (known)

The random effects follow a bivariate normal: \[(u_{i1}, u_{i2})' \sim N(0, G)\]

where \(G\) is the between-study covariance matrix: \[G = \begin{pmatrix} \tau_{11} & \tau_{12} \\ \tau_{12} & \tau_{22} \end{pmatrix}\]

Key Quantities

Quantity Formula Interpretation
\(R^2_{between}\) \(\tau_{12}^2 / (\tau_{11} \times \tau_{22})\) Between-study correlation squared
\(\eta\) \(\tau_{12} / \tau_{11}\) Translation coefficient
Conditional Variance \(\tau_{22} - \tau_{12}^2 / \tau_{11}\) Residual variance after conditioning

Conditional Expectation

The translation coefficient \(\eta\) enables prediction of one endpoint from another: \[E(Y_2 | Y_1) = \mu_2 + \eta \times (Y_1 - \mu_1)\]

Example 1: AAA Growth and Rupture

The RESCAN collaboration collected data on abdominal aortic aneurysm (AAA) growth rates and rupture risk across 18 centers, stratified by initial diameter (30, 35, 40, 45, 50 mm). This example is based on Figure 3 from Rabbee (2026). It uses the package defaults (unstructured \(G\) and Satterthwaite confidence intervals), so the RuptureRisk estimates and all confidence intervals differ somewhat from the paper. To reproduce the published Table 1, add struct = "CS", satterthwaite = FALSE to the slim_fit() call.

By default slim_fit() fits an unstructured \(G\) (struct = "UN"), so \(\tau_{11}\), \(\tau_{12}\) and \(\tau_{22}\) are all estimated and \(\eta = \tau_{12}/\tau_{11}\) as defined above. The option struct = "CS" forces \(\tau_{11} = \tau_{22}\), which makes \(\eta\) equal to the correlation. The confidence intervals for the pooled means use cluster-robust (CR2) variance estimation with Satterthwaite degrees of freedom, a small-sample correction (satterthwaite = TRUE); the df column of result$pooled gives the degrees of freedom. Set satterthwaite = FALSE for plain Wald intervals.

Interpreting \(\eta\) and \(R^2\)

\(\eta\) (eta) answers: “By how much?” It is calculated on the transformed scale and is not back-transformed.

In this example, GrowthRate is untransformed (mm/year) while RuptureRisk is log-transformed. So \(\eta\) = 0.789 means: a 1 mm/year increase in growth rate corresponds to a 0.789 increase in log(rupture risk).

To interpret on the original scale: \(\exp(\eta) \approx\) 2.2, meaning rupture risk is multiplied by about that factor for each 1 mm/year increase in growth rate.

\(R^2\) (between-study) answers: “How predictable is the relationship?” It measures how much of the between-study variance in endpoint 2 is explained by endpoint 1.

\(R^2\) = 0.46 means 46% of the variation in rupture risk across centers is explained by their growth rates. The remaining 54% is due to other factors (patient mix, measurement differences, etc.).

Step 2: Visualize (based on Figure 3 from Rabbee 2026)

The following code generates plots comparing SLIM model estimates with observed means, similar to Figure 3 in the paper:

library(ggplot2)
library(gridExtra)

# Get pooled estimates from the model
res <- result$pooled

# Calculate observed means from data
obs_growth <- aggregate(Mean ~ Diameter,
                        data = subset(aaa, Endpoint == "GrowthRate"),
                        FUN = mean)

obs_rupture <- aggregate(Mean1000 ~ Diameter,
                         data = subset(aaa, Endpoint == "RuptureRisk"),
                         FUN = mean)
obs_rupture$Endpoint <- "RuptureRisk"
names(obs_rupture)[2] <- "Observed"

obs <- rbind(obs_growth, obs_rupture)
obs$Diameter <- as.numeric(as.character(obs$Diameter))

# Merge model estimates with observed

Step 3: Test for Heterogeneity in Eta

Does the translation coefficient differ across diameter strata?

# Cochran's Q test for eta heterogeneity
eta_test <- slim_eta_by_stratum(
  data          = aaa_fit,
  strata_col    = "Diameter",
  endpoints     = c("GrowthRate", "RuptureRisk"),
  trial_col     = "Study",
  endpoint_col  = "Endpoint",
  y_col         = "y",
  se_col        = "se",
  transform     = list(RuptureRisk = "log")
)

eta_test$Q_test  # Q statistic and p-value
$Q
[1] 2.774

$df
[1] 4

$p_value
[1] 0.5964

The Q test does not reject a common \(\eta\) across the diameter strata (\(p > 0.05\)). With only a few centers per stratum the stratum-specific estimates of \(\eta\) are imprecise, so this test has limited power; a non-significant result is not evidence that \(\eta\) is the same in every stratum.

Example 2: Obesity Drug Classes (Conceptual)

For obesity trials comparing GLP-1 vs GIP agonists with endpoints WeightLoss and HbA1c:

# Fit SLIM with drug class as stratum
result <- slim_fit(
  data         = obesity_data,
  formula      = ~ 0 + Endpoint:DrugClass,
  random       = ~ Endpoint | Study,
  trial_col    = "Study",
  endpoint_col = "Endpoint",
  y_col        = "Effect",
  se_col       = "SE"
)

# Test if eta differs by drug class
eta_test <- slim_eta_by_stratum(
  data       = obesity_data,
  strata_col = "DrugClass",
  endpoints  = c("WeightLoss", "HbA1c"),
  ...
)

dunnett <- slim_eta_dunnett(
  result         = result,
  eta_by_stratum = eta_test,
  data           = obesity_data,
  strata_col     = "DrugClass",
  ...
)

# If p < 0.05: GLP-1 and GIP have different translation coefficients
# This would mean the weight loss -> glycemic control relationship
# differs between drug mechanisms

Pre-Processing: Handling Extreme Rate Ratios

When rate ratios or risk ratios are very close to zero (e.g., rare events), even log-transformation can produce unstable estimates with huge standard errors. These extreme values can dominate the meta-analysis.

The slim_prior_adjust() function applies Bayesian shrinkage before stacking:

# Original data has some rate ratios near zero
data_adj <- slim_prior_adjust(
  data       = mydata,
  y_col      = "log_RR",
  se_col     = "SE_log_RR",
  prior_type = "normal",
  prior_mean = 0,         # no effect (RR = 1 on original scale)
  prior_sd   = 1.0        # weakly informative
)

# Visualize the shrinkage
slim_prior_plot(data_adj, "log_RR", "SE_log_RR")

# Use adjusted values in SLIM
result <- slim_fit(
  data     = data_adj,
  y_col    = "log_RR_adj",
  se_col   = "SE_log_RR_adj",
  ...
)

How it works: For a normal prior and observed effect \(y\) with SE \(\sigma\):

\[\text{posterior mean} = \frac{y/\sigma^2 + \mu_0/\tau^2}{1/\sigma^2 + 1/\tau^2}\]

Studies with large SEs (unstable estimates) are shrunk more toward the prior mean; studies with small SEs (precise estimates) retain their original values.
